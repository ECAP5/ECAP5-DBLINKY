Configuration
=============

Instanciation parameters
------------------------

ECAP5-DBLINKY can be parameterized at build-time through instanciation parameters. Default constant values are defined for such parameters.

.. list-table:: Instanciation parameters of ECAP5-DBLINKY
  :header-rows: 1
  :width: 100%
  :widths: 10 10 10 70 10

  * - Name
    - Type
    - Width
    - Description
    - Default value

  * - INPUT_FREQ
    - integer
    - N/A
    - Frequency of clk_i in Hz
    - 40000000
